# 09 - Copyable links

Status: ready-for-agent
Type: task
Blocked by: 03

Posting needs a GitHub account, and on a managed laptop the browser that can open GitHub is often
not this one. A button that opens a tab the user cannot sign into is no help; text they can paste
into an email is.

Two places:

- Beside the GitHub caveat on the feedback form, a copyable link to the issues page, so a user can
  send the report and its destination to someone who can post it.
- In the About block, a copyable link to the repo, so a user can pass the extension on however
  they like.

Show the real URL rather than a label. It is what gets copied, and hiding it helps nobody.
